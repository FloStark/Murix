Website-Relaunch ohne
Rankingverlust.

Ein Relaunch ist die beste Chance, Technik, Design und Inhalte zu verbessern. Ohne SEO-Plan kann er aber wertvolle Google-Rankings kosten.

17. Juli 20268 Minuten LesezeitFür KMU & Dienstleister

Viele Relaunch-Projekte starten mit Designfragen: moderner Look, neue Texte, schnellere Ladezeiten. Für Suchmaschinen zählt zusätzlich, ob URLs, Inhalte, interne Links und technische Signale sauber übernommen werden. Die folgende Checkliste hilft, typische Rankingverluste zu vermeiden.

1. Vor dem Relaunch: Ist-Zustand sichern

Bevor eine bestehende Website verändert wird, sollten die wichtigsten SEO-Daten dokumentiert werden. Dazu gehören alle indexierten URLs, aktuelle Rankings, Seiten mit organischem Traffic, Backlinks und die bestehenden Meta-Titel und Beschreibungen. Ohne diesen Stand ist später kaum nachvollziehbar, welche Änderung ein Problem verursacht hat.

Für kleine Websites reicht oft eine saubere Tabelle mit URL, Seitentitel, Zielkeyword, aktuellem Status und geplanter neuer URL. Bei größeren Projekten ist ein technischer Crawl sinnvoll.

2. URL-Struktur nicht unnötig ändern

Jede geänderte URL ist ein Risiko. Wenn eine Seite bereits gut rankt, sollte die URL möglichst erhalten bleiben. Muss sie geändert werden, braucht sie eine permanente 301-Weiterleitung auf die passende neue Seite. Weiterleitungen auf die Startseite sind nur eine Notlösung und verlieren oft Relevanz.

Praxisregel: Jede alte URL bekommt genau eine passende neue Ziel-URL. Keine Weiterleitungsketten, keine 404-Fehler, keine pauschale Weiterleitung auf die Homepage.

3. Inhalte mit Suchintention übernehmen

Beim Relaunch werden Texte häufig gekürzt, weil das neue Layout schlanker wirken soll. Das kann sinnvoll sein, wenn Inhalte redundant sind. Kritisch wird es, wenn genau die Abschnitte entfernt werden, die für gute Rankings verantwortlich waren: FAQs, Leistungsdetails, regionale Begriffe, Preise oder klare Nutzenargumente.

Prüfen Sie deshalb jede wichtige Seite: Welche Suchanfrage soll sie beantworten? Welche Fragen stellt ein potenzieller Kunde? Welche internen Links führen weiter? Aus SEO-Sicht ist ein Relaunch dann gelungen, wenn Design und Inhalt gemeinsam stärker werden.

4. Technik, Performance und Core Web Vitals prüfen

Eine neue Website sollte schneller, stabiler und mobiler werden. Besonders wichtig sind komprimierte Bilder, sauberes HTML, sinnvolle Überschriftenstruktur, schnelle Fonts und möglichst wenig unnötiges JavaScript. Statische Websites haben hier oft Vorteile, weil keine Datenbank und kein schweres Theme geladen werden müssen.

Mehr dazu finden Sie in unserem Vergleich Static Pages vs CMS.

5. Meta-Daten, Canonicals und strukturierte Daten aktualisieren

Jede relevante Seite braucht einen eindeutigen Title, eine überzeugende Meta-Description und eine korrekte Canonical-URL. Für lokale Unternehmen sind zusätzlich strukturierte Daten wie LocalBusiness, Service oder Article hilfreich. Sie ersetzen keine guten Inhalte, helfen Google aber beim Verständnis der Seite.

6. Nach dem Go-live sofort kontrollieren

Direkt nach Veröffentlichung sollten Sitemap, Robots.txt, Canonicals, Weiterleitungen und 404-Fehler kontrolliert werden. In der Google Search Console kann die neue Sitemap eingereicht und die Indexierung wichtiger Seiten geprüft werden. Die ersten Tage nach dem Go-live sind entscheidend, weil technische Fehler hier schnell sichtbar werden.

Fazit

Ein Website-Relaunch ohne SEO-Konzept ist unnötig riskant. Wer URLs, Inhalte, Weiterleitungen und technische Grundlagen sauber plant, kann Rankings nicht nur halten, sondern verbessern. Wenn Sie eine neue Website planen, lohnt sich eine frühe SEO-Prüfung vor dem Designfinale.
